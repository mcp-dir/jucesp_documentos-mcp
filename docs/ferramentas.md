# Ferramentas

JUCESP: Lista de Documentos expõe 1 ferramenta (todas somente leitura).

### 1. `jucesp_documentos_consultar`
**Input**: `login_cpf` (opcional), `login_senha` (opcional), `pkcs12_cert` (opcional), `pkcs12_pass` (opcional), `nire`

Lista os documentos arquivados de uma empresa na JUCESP a partir do NIRE.

## Prompts de exemplo

```
Documentos arquivados do NIRE na JUCESP
```
